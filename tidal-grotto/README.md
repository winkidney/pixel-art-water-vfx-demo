# 石桥清潭 · 像素水体实验

独立 Godot 4 Mini 项目。默认场景采用已确认的 D3R、N3R 宽瀑布设计，可即时切换白天和夜晚。场景与四方向角色由内置 ImageGen 生成，水面、角色浸没和瀑布流动由 Godot 实时绘制。

## 运行

使用 Godot 4.7.2 打开 `project.godot`，等待导入后按 F5。项目使用 Compatibility 渲染器，无需插件、Python 或在线服务。实际验证版本为 4.7.2。

默认自动从石阶走入浅水和深水，再返回岸上。按移动键或点击场景即可接管。右上角切换白天、夜晚，角色位置、潮位和交互状态随之保留。窗口为 1280×800，场景在 480×320 视口内绘制后放大 2 倍。

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 自由移动 |
| 点击场景 | 前往目标并绕过礁石；点击水面也会产生涟漪 |
| 空格 | 在角色出水位置激起涟漪 |
| Tab | 查看清理后的 ImageGen 底图，再按一次恢复效果 |
| P | 冻结 / 恢复时间 |
| R | 重置位置、潮位、扰动、效果和漫游，保留当前时段 |
| F12 | 截图保存到项目内 `captures/` |

右侧可独立开关九项效果，调节水面扰动和潮位，并查看水深。潮位改变水色和角色浸没程度，地形淹没边界固定。

## 本次迁移

两张生产底图保存在 `assets/stone-basin/`。ImageGen 移除了概念图中预先画好的角色、角色倒影、交互涟漪、岸线白边和大面积水面反光。保留海床、石阶、桥、礁石，以及宽瀑布与落水泡沫，作为运行时采样来源。夜晚版以清理后的白天图为几何参照重新打光。

两版共用水域、水深、行走和遮挡数据。水下石块不会自动变成干地；两组突出的珊瑚礁、岩壁和瀑布落点不可穿行。石桥在此版本中作为环境结构和水路拱门，没有额外的桥面行走层。

水体保留原实验的深浅色阶、像素折射、焦散、岸边泡沫、交互涟漪、角色倒影和渐进浸没。新增连续宽瀑布的向下流动、落点泡沫扰动与汇流波，以及夜间月光、暖灯反光和桥身颜色投影。前景遮挡采样原画颜色，并根据角色脚点切换前后关系，棕榈叶片间隙仍可看见动态水面。

美术清理使用内置 ImageGen。完整提示词、来源文件、输入角色、哈希及验证说明见 [迁移记录](docs/stone-basin/README.md)。原始已确认概念图保存在同级 `designs/stone-basin-widefall-v5/`，没有覆盖。

## 实现边界

这是二维水体效果实验。水深由手工岸线和距离场近似；环境倒影使用二维投影与函数光带，没有三维反射相机。瀑布使用生成原画、技术遮罩和流动采样，关闭瀑布开关后保留静态底图中的瀑布。角色复用四方向站姿，加程序摆动和浮动，尚无逐帧游泳动作。

技术遮罩由 `tools/build_stone_basin_maps.py` 生成，R/G/B/A 分别表示水域、岸线距离、水深与可行走区域。遮罩导入必须保持 `process/fix_alpha_border=false`，避免非透明数据通道被当作普通美术图片修补。

## 验证与复查

真实图形窗口验证覆盖两版的输入、往返漫游、绕行、浸没、九项开关、动画、冻结、遮挡和 2 倍像素网格。报告及截图位于同级 `evidence/stone-basin/`，30 秒实机录像位于同级 `stone-basin-day-night-demo.mp4`。短时性能结果只代表记录中的机器。

在项目目录运行以下命令，需要真实图形会话：

```sh
godot --path . --script res://scripts/audit_stone_basin.gd
python3 tools/check_stone_basin_render.py
```

图像检查与遮罩重建需要 Pillow、NumPy、SciPy。项目运行不需要这些依赖。重建遮罩后让 Godot 重新导入：

```sh
python3 tools/build_stone_basin_maps.py
```

原始洞窟实验与旧证据保留。命令行追加 `-- --legacy` 可运行原场景；旧版说明见 [原实验记录](docs/legacy-readme.md)。
