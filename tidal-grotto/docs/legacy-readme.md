# 潮汐洞窟

一个独立的 Godot 4 像素水体实验。场景、四方向角色均由内置 ImageGen 生成。水深、折射、焦散、岸边泡沫、交互涟漪、角色倒影和渐进浸没由运行时绘制。

## 运行

使用 Godot 4.7.2 打开 `project.godot`，等待素材导入后按 F6 或 F5。项目使用 Compatibility 渲染器，不需要第三方插件或在线服务。代码使用 Godot 4 API，实际验证版本为 4.7.2，其他版本未逐一验证。

默认自动漫游一圈，从沙滩进入浅水和深水后返回。按移动键或点击场景即可接管。默认窗口 1280×800，场景以 480×320 绘制并放大 2 倍。所有动态效果先进入低分辨率视口，避免水体与地形采用不同像素网格。

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 自由移动 |
| 点击场景 | 前往目标，自动绕过主岩壁与棕榈岛；水面点击也会产生涟漪 |
| 空格 | 在角色出水位置激起涟漪 |
| Tab | 切换 ImageGen 原始底图与完整效果 |
| P | 冻结 / 恢复时间 |
| R | 重置位置、潮位、扰动、所有效果和漫游 |
| F12 | 将当前窗口截图保存到项目内的 captures 文件夹 |

右侧可逐项开关效果，调节扰动和水位偏移，查看深度图。水位滑杆改变吸收色和角色浸没程度。岸线泡沫会往复移动，整个地形的淹没边界目前固定。

## 实现

`assets/shoreline.json` 是对应当前场景的手工语义轮廓。`assets/bathymetry.png` 的 R 通道表示水域，G 表示岸线距离，B 表示归一化水深，A 表示可行走区域。水深使用轮廓距离与南侧浅滩趋势近似，不是三维地形测量结果。

`shaders/water.gdshader` 只修改水域。折射偏移量按逻辑像素取整，并拒绝采样岸外像素。焦散采用移动的函数纹理，深水中逐渐减弱。泡沫沿距离场移动。最多保留 16 个交互波纹，在水中运动或点击时产生，按时间衰减。

`shaders/character.gdshader` 依据角色局部高度和横向曲线决定水线，水下部分变色、变淡并轻微扰动，水线有亮边。角色当前使用四方向站姿，加程序摆动和浮动，没有完整的逐帧行走或游泳动作。深水上限保留头部可见。

`shaders/reflection.gdshader` 使用角色翻转副本、透明衰减和扰动近似倒影。它受水域遮罩约束。当前没有岩壁、棕榈树的实时场景反射，也没有三维反射相机。

小岛与主岩壁的绕行使用 2 像素网格的 AStarGrid2D。水下岩石属于海床，可越过。单张生成场景中的全部石块没有逐个建立物理碰撞。

## 美术与参考

原始生成图保存在 `assets/grotto-imagegen.png` 与 `assets/adventurer-imagegen.png`。项目直接使用生成结果，角色在运行时按透明度阈值取四个方向的有效区域。生成模式、完整提示词、文件哈希见 [ImageGen 记录](docs/imagegen.md)。

参考内容和实现取舍见 [参考与实验说明](docs/references.md)。原始底图本身已有静态水色、少量白色岸线和瀑布。这些静态内容在关闭实时效果时仍然可见。当前瀑布是静态背景，未单独动画化。

## 验证

真实图形窗口验证使用 Godot 4.7.2、OpenGL Compatibility、NVIDIA RTX 4070 SUPER。检查范围包含键盘移动、点击目标、绕行、自动往返、深浅变化、水位偏移、重置和各效果开关。截图、渲染差异检查、运行报告位于同级 `evidence/`。运行报告记录的是该机器上的短时窗口运行结果，不能代表其他设备性能。

具体数值与检查边界见 [验证结果](docs/validation.md)。

复查可运行 `godot --path . --script res://scripts/audit.gd`。需要真实图形会话，headless 的空渲染器不能验证画面。审核脚本会把截图和报告写入项目上一级的 evidence 文件夹。

随后可执行 `python3 tools/check_render.py` 核对岸外像素、2 倍美术像素网格和各效果差异。这个可选检查与遮罩重建使用同一组 Python 依赖。

项目包含生成好的遮罩，运行时不依赖 Python。需要重建技术遮罩时，可以安装 Pillow、NumPy、SciPy 后执行 `python3 tools/build_maps.py`，随后让 Godot 重新导入。替换场景图时必须同时重新校准语义轮廓。
