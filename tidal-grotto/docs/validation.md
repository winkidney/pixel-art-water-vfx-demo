# 验证结果

2026-11-01，真实窗口渲染。

- Godot: 4.7.2-stable (official)
- GPU: NVIDIA GeForce RTX 4070 SUPER
- 预热 2 秒，随后测量 3.017 秒，窗口平均 60.002 FPS。
- 采样结束时主线程 process 时间 0.623 ms，此值不等同于整帧或 GPU 时间。
- 键盘输入实际移动 4.59 逻辑像素。点击、潮位、重置、岩壁阻挡、小岛绕行和自动往返均通过。
- 五个采样点的归一化水深按岸边到水盆顺序为 0.0%, 6.8%, 33.4%, 94.3%, 96.0%。
- 原图与完整效果在水域之外的变化像素数为 0。
- 两个不同时刻有 62315 个水域像素变化。
- 2 倍放大的美术像素网格检查通过；左上角高分辨率状态文字作为 UI 排除。
