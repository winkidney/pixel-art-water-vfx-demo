# Godot Demo

使用 Godot 4.7.2 导入本目录中的 [project.godot](project.godot)，等待导入后按 F5 运行。默认场景为石桥清潭，可切换白天与夜晚。

[项目入口](../README.md) · [运行与验证](../docs/guides/running.md) · [手工调参](../docs/guides/parameters.md) · [158 项参数参考](../docs/guides/parameter-reference.md)

生产资源位于 assets/，脚本位于 scripts/，着色器位于 shaders/。文档、视频和制作素材位于工程之外。
