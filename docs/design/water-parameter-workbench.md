# 水体手工调参设计访谈

状态：已实现并完成实机验收。日期：2026-11-01。

用户希望各个参数可手工调整、提供默认值，并即时观察效果。访谈按 grill-with-docs、grilling 与 domain-modeling 技能进行；访谈阶段仅记录事实与待选方案；用户在 Q12 最终确认后，已按方案实现并完成实机检查。

## 已核查现状

- 运行界面提供九个效果开关，默认全部开启。
- 水面扰动默认 1，滑杆范围 0 到 2，步长 0.05。它只缩放水面折射位移，不能停止所有动画。
- 潮位偏移默认 0，范围 -0.7 到 0.7，步长 0.02。它改变水色和角色浸没程度，当前岸线不随之移动。
- 清澈度已有着色器参数，默认 0.65，但无界面入口。
- 现有滑杆没有数值读数、数值输入框或逐项恢复默认按钮。
- 白天与夜晚切换保留位置、时间、效果开关和当前手调状态。水色、角色色调由时段影响。
- 当前重置会同时恢复位置、时间、潮位、扰动、效果开关和漫游，并解除冻结；保留所选时段。
- 材质由脚本运行时创建，未提供检查器参数资源；部分值每帧被脚本赋值，直接改材质值可能被覆盖。
- 未发现参数配置或预设保存、加载逻辑。现有 F12 功能保存截图。

| 分组 | 候选项 |
| --- | --- |
| 水色与深浅 | 清澈度、浅水色、深水色、水色混合强度、深浅变化 |
| 波动与折射 | 位移强度、波纹尺度、运动速度 |
| 焦散 | 亮度、颜色、图案密度、线宽、移动速度 |
| 岸线泡沫 | 颜色、透明度、宽度、离岸距离、往复幅度、速度 |
| 交互涟漪 | 生命周期、扩散速度、环宽、强度、触发间隔 |
| 瀑布与汇流 | 水幕流速、滚动距离、流纹强度、泡沫扰动、汇流速度与衰减 |
| 环境倒影与光带 | 倒影强度、压缩、扭曲；月光及暖灯的颜色、强度、宽度与摆动 |
| 角色浸没与倒影 | 水下色、透明度、折射、水线、倒影透明度和扭曲 |

用户已选择开放完整美术参数，具体参数清单将在实施设计中列出。水域遮罩格式、像素分辨率、导航网格、纹理裁剪、涟漪数组容量和构图锚点需要与美术参数区分。

## 第一轮已确认

1. 使用运行中控制面板，按效果分组折叠，提供滑杆、精确数值输入、默认值显示和逐项恢复，调整立即生效。
2. 开放完整美术参数，包括颜色、强度、速度、尺寸、透明度和衰减，区分常用与高级选项；技术设置固定。
3. 以当前已经采用的白天和夜晚效果为默认基准。
4. 手动保存、加载命名预设，原始默认值始终保留。

以上为用户明确选择。用户已在 Q12 确认完整方案并授权开始实现。

## 第二轮已确认

1. 白天与夜晚共用一套调整值。切换时只改变底图和时段光色，不建立两套独立用户参数。
2. 恢复默认只修改美术参数；重置场景只处理位置、时间和漫游状态，二者分离。
3. 所有参数使用足够宽的有效固定范围，滑杆和精确数值输入遵守相同限制；无效输入提示后不应用。
4. 提供本机命名预设保存、加载，并支持可读文件的导入和导出。

其中第 1 项采用用户选择，覆盖上一轮的独立时段参数建议。白天/夜晚继续保留各自的色彩基准，用户已在第三轮选择共享相对调色。

## 第三轮已确认

1. 采用共享相对调色，白天与夜晚各自保留基准光色。色相偏移、饱和度倍率和亮度倍率作用于对应时段的基准色，原始基准色不被覆盖。
2. 命名预设保存美术参数以及保存时的时段。加载或导入预设同时应用参数并切换到所存时段，保留角色位置、场景时间、冻结及漫游状态。
3. 存在未保存修改时，加载、导入、恢复全部默认或退出均直接执行，不弹出保存确认，不自动保存。需要保留时由用户事先手动保存。

第 2、3 项采用用户选择，分别覆盖“只加载参数并保留时段”和“先提示保存”的建议。

## 最终交互方案

- 右侧改为可滚动的运行中调参面板，按水色、波动与折射、焦散、岸线泡沫、交互涟漪、瀑布与汇流、环境反光、角色浸没、角色倒影分组折叠。
- 常用项优先显示，高级项可展开。每项展示中文名称、当前值、默认值、有效范围及适用单位，支持滑杆和精确数值输入；效果开关保留。
- 相对调色提供色相偏移、饱和度倍率和亮度倍率，显示当前时段的基准色与调整后的色样。默认分别为 0 度、1 倍、1 倍，默认画面与现有版本一致。
- 单项恢复默认、分组恢复默认、全部参数恢复默认只改参数，不改时段、位置、场景时间、冻结或漫游状态。
- 重置场景只恢复起点、场景时间、路径、临时涟漪和漫游初态，不改当前参数和时段；沿用原有场景重置的解除冻结行为。
- 切换白天/夜晚保留同一套用户调整；仅加载预设时按预设记录切换时段。显示未保存状态作为信息提示，不阻止直接操作。
- 保留现有冻结、原图/深度查看、截图和自由移动操作。编辑数值或预设名称时，输入焦点不触发角色移动或其他场景快捷键。
- 启动时使用原始默认参数；保存和加载均由用户明确操作。预设包含名称、格式版本、共享参数和保存时段，不记录角色位置或场景时间。
- 预设支持本机保存/加载及可读 JSON 文件导入/导出。显式保存同名预设时覆盖该预设，不增加保存确认弹窗。原始默认值不被预设保存覆盖。
- 滑杆、数值输入和预设文件均使用同一份参数定义及校验规则。超出范围或非法数值不应用；导入失败保持当前画面与状态，不做部分替换；错误在面板显示。
- 下列为实现时的参数目录和取值建议：[参数目录](water-parameter-catalog.md)。默认值来自当前代码，新增相对控制采用中性默认。具体步长由数值精度和单位决定，范围遵守用户已选择的固定有效范围。

## 验收标准

1. 白天和夜晚采用默认值时，对照现有固定位置、固定时刻的运行截图；任何画面变化均需查明，不能用替换参考图掩盖默认效果漂移。
2. 每项参数具有单一默认值和有效范围，面板读数与实际生效值一致；没有因每帧脚本覆盖而失效的假控件。
3. 分组抽查颜色、强度、速度、尺寸、透明度及衰减，验证运行时立即变化。夜间专属参数明确标注适用时段。
4. 白天调整后切到夜晚再返回，共享调整值不变，时段各自基准光色保留。
5. 各级恢复默认不改变场景状态；重置场景不丢参数；输入框获得焦点时快捷键不影响场景。
6. 预设保存/加载/导出/导入往返一致，加载恢复保存时段，位置、时间及冻结状态保持；原始默认值不被修改。
7. 修改未保存时，各覆盖或退出操作直接执行，不出现保存确认。非法输入、损坏预设不能导致一部分参数已更新。
8. 检查真实图形窗口的交互、像素对齐和帧率；保留 60 FPS 策略及既有水域、导航和遮挡检查。

用户已在 Q12 最终确认，没有剩余需求分支。当前决定均易于调整，不建立 ADR。实现覆盖 158 个控制项，158 项逐项验证、面板与预设检查及原有场景回归均通过，结果见 `evidence/parameters/README.md`。
