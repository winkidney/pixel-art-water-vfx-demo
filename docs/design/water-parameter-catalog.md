# 水体参数目录

状态：用户已确认，参数目录已实现。基线为当前项目 `0d4e60f` 的运行代码。默认数值沿用现有画面；本表范围已用于实现，所有输入方式使用同一范围。

“完整美术参数”覆盖具有独立视觉意义的颜色、强度、速度、尺度、透明度和衰减。数学防零常数、遮罩格式、像素网格、数组容量、素材裁剪及场景锚点保持技术设置；不将每一个公式常数机械地变成滑杆。

所有像素单位均为 480×320 场景中的逻辑像素；只有明确注明“源纹理像素”的角色采样位移采用源纹理单位。角度为度，时间为秒，倍率为无量纲。

## 默认值与控制规则

- 九个效果开关默认全部开启，可独立控制。
- 每个数值参数显示当前值、默认值、范围和单位，提供单项恢复。数值修改立即生效。
- 色彩用相对调整表示，每个相关颜色目标分别提供色相偏移 0 度、饱和度倍率 1、亮度倍率 1。有效范围分别为 -180 到 180 度、0 到 3 倍、0 到 3 倍。
- 默认相对调色保持原始 RGB；不通过重新调色改变默认画面。切换时段保持这些调整值，改用对应时段基准。
- 速度设为 0 时，相应运动停止；整体时间冻结功能仍独立存在。改变速度时以连续相位控制，避免整个图案突然跳变。
- 表中“倍率 1”是新开放控制的中性默认，仍使用原公式的基础系数，因此不代表重设原画风格。
