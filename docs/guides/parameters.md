# 手工调参

打开项目按 F5，右侧是运行中调参面板。场景仍以 480×320 绘制并放大 2 倍，窗口加宽至 1440×800，为数值输入留出空间。

## 调整和比较

展开一个效果组后拖动滑杆，或输入数值并按回车。每项下方显示默认值和有效范围，右侧 ↺ 恢复单项默认；组标题旁的 ↺ 恢复整组。高级开关显示更多控制和相对调色；搜索可直接定位参数，包括隐藏的高级项。

白天与夜晚共用参数。调色使用色相偏移、饱和度倍率和亮度倍率，保持各时段本来的光色基准。默认分别为 0 度、1 倍、1 倍。色样显示参考色与调整后颜色；月光、暖灯和夜间角色色调标注夜间适用。

先冻结时间可比较同一画面。速度在冻结时不会推动图案，恢复时间后可看到新速度；调整速度保留当前相位，避免图案跳动。Tab 查看底图，深度图按钮检查水深，F12 截图。

输入框编辑期间，场景移动和快捷键不会响应，防止输入文字时角色误动。数值回车后释放焦点；点击场景也可返回场景操作。

## 默认值和重置

“恢复参数”恢复全部美术参数，保留时段、角色位置、场景时间和播放状态。“重置场景”及 R 将角色、时间、路径、涟漪和漫游恢复初态并解除冻结，保留全部手调参数和当前时段。

启动使用原始默认值。全部 [158 项的默认值与范围](parameter-reference.md) 来自 `demo/assets/water-parameters.json`，运行时、面板与预设校验共用此定义。非法数值不应用，面板会说明错误。

## 预设

1. 输入名称，点击“保存”。同名保存直接覆盖。
2. 在下拉框选择已保存预设，点击“加载”。加载参数并切换到保存时段，保留角色位置、场景时间、冻结和漫游状态。
3. “导出”选择目录，写出“预设名称.json”。“导入”选择 JSON 文件，校验后加入本机预设并加载。

本机预设保存在 Godot 用户数据的 `water-presets` 目录，不修改原始默认值和项目素材。关闭程序不会自动保存；加载、导入、恢复默认或退出均直接执行，不弹保存确认。面板的“未保存修改”仅作提示，需要保留时请事先保存或导出。

损坏文件、错误格式、未知参数及超范围数值会被拒绝；导入失败时原参数和画面状态保留。预设带版本号、名称、共享参数和保存时段，不保存人物位置或场景时间。

## 复查

在仓库根目录的图形会话中运行：

```sh
godot --path demo --script res://scripts/audit_parameters.gd
godot --path demo --script res://scripts/audit_parameter_coverage.gd
godot --path demo --script res://scripts/audit_stone_basin.gd
python3 tools/check_stone_basin_render.py
```

前两个脚本检查面板、预设和 158 项参数实际效果；第三个检查原有场景功能。证据保存至同级 `evidence/parameters/`，旧版截图保留作默认画面对照。测试预设写入项目上级的 `.local/work/`，不污染日常使用的本机预设。

参数参考可通过 `python3 tools/generate_parameter_reference.py` 重新生成。

在干净 Git 工作区可运行 `python3 tools/package_demo.py` 生成`.local/dist/pixel-art-water-vfx-demo.zip` 压缩包。打包包含源码、已采用概念图、演示和验收记录，排除缓存及本机预设，并校验每个文件的内容哈希。
