# 运行中调参验收

使用 Godot 4.7.2、OpenGL Compatibility、NVIDIA RTX 4070 SUPER 的真实窗口。未用 headless 空渲染代替视觉验证。

- 参数定义与控制项：158 项，逐项检查全部通过。154 项采用实际 GPU 画面差异，4 项触发参数检查实际涟漪事件与间隔。
- 逐项测试先隔离其他状态，在非零潮位检查潮位影响，在适合像素位移的位置检查静止摆动。测试多组固定时刻，不将其他参数产生的变化计作当前参数有效。
- 面板与预设：27 项检查通过，包括真实鼠标滑杆、数值输入、搜索、恢复、共享值、所有速度连续相位、焦点保护、损坏文件与预设往返。
- 默认值：白天、夜晚均与原石潭基线逐像素一致，变化 0 像素。
- 场景回归：两版的键盘、点击、绕行、完整漫游、深浅水、冻结、各层效果和遮挡通过；岸外修改和瀑布越界均为 0，保留严格 2 倍美术像素。
- 新面板窗口帧率：逐项验收结束后预热测量 60.00 FPS；场景回归白天 60.01 FPS、夜晚 60.01 FPS。
- 普通窗口进程时间中位数：白天 1.404 ms、夜晚 0.993 ms。它是 Godot 监视器读数，不是独立 GPU 着色计时。
- 保留的旧洞窟场景回归另见 legacy-regression/runtime-report.json。

完整结果见 runtime-report.json、coverage-report.json、default-baseline-checks.json 及 scene-regression/。日常预设未被测试修改；测试文件位于被忽略的 work/。

此结果代表当前机器上的短时窗口运行，未逐一验证其他平台。
