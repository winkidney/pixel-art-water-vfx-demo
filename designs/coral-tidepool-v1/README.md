# 珊瑚潮池 · 场景设计 v1

状态：等待用户确认设计。此目录仅包含场景设计资料，没有替换现有 Godot 资源或迁移水体效果。

## 设计目标

以用户提供的像素 JRPG 图为美术参考，重新设计一处可从砂岸进入浅水、再进入深水的潮池。保持低饱和蓝绿色水面、暗褐色层叠岩柱、灰米色沙岸、橄榄绿植物，以及少量洋红和青色珊瑚。使用可辨认的大像素块与材质色阶，减少细碎噪点。

## 场景构图

- 左侧为主要岩壁与蜿蜒沙径，中央偏左形成宽缓的入水坡。
- 主水域位于中心和右侧，保留连续的浅深过渡与开放游动区域。
- 右侧独立棕榈礁岛与后方落水口提供视觉焦点，也用于后续检验水域遮罩和遮挡。
- 前景岩石、藤蔓和珊瑚集中成组布置，让路径与岸线保持可读。

设计画幅沿用当前实验的 3:2；目标逻辑网格为 480×320。生成图是设计参考，实际像素网格、边缘和分层在确认后的制作阶段验证，不能仅凭提示词认定已经满足技术网格。
