# 幽潮渡口 · 场景设计 v3

状态：等待用户确认设计。本版为新的独立方案，尚未接入运行项目。

参考用户本轮提供的幽暗沿海遗迹图，采用阴雨傍晚、深绿色水域、灰褐岩台、旧木栈道与青绿色灯火。此前冬季稿保留，本版按新参考的阴雨氛围设计。

## 构图与路线

- 左侧为连续岩体、分层木平台及连接上下层的短楼梯，避免切开左侧道路的深裂隙。
- 左下低岸安排缓坡浅滩，连接主水面，为后续水深过渡和入水效果预留区域。
- 右侧独立岩台以细窄绳索木桥连接左侧高处，形成与涉水路线分开的过桥路线。
- 主水域保留开放空间，青绿灯火集中照亮落脚点与木桩，水上倒影作为视觉重点。

## 后续水体接入方向

确认设计后，再制作对应的海床、前景栈道与支柱、水域遮罩、岸线距离和连续深度数据。沿用既有水深色阶、折射、涟漪和角色浸没效果，按本版幽暗配色调整可见度，并单独评估灯火倒影。上述接入尚未执行。

设计图中的雨丝、波纹、灯火和倒影为静态美术示意，不作为实时效果完成的证据。目标画幅 3:2，目标逻辑网格 480×320；实际像素网格与分层在确认后的制作阶段验证。
