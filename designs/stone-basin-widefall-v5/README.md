# 石阶泉湾 · 整幅宽瀑布修订 v5

用户已采纳九稿中的 D3、T3、N3，分别对应白天、黄昏、夜晚。本轮沿用这组场景，按用户要求修订瀑布和细节组织。选择来源记录在 ../selection.json，原九稿保持完整。

## 本轮调整

右侧原本分段、错落的瀑布改成一整幅较宽的连续水幕，从统一崖口落下，直接汇入同一主水域。保留后方石拱桥、左侧石阶与岸台、主要岩岸、棕榈树、珊瑚组和测试角色位置。瀑布区域是本轮主要几何调整处。

用户要求适度“归约细节灭高频冗余，软泛焦均质简谐流”。执行上将相近颜色合并成连贯像素簇，减少岩面碎斑、孤立草叶亮点、颗粒沙纹、细密白色焦散网和零散水面闪点。保留岩体体积、水下石阶、岸线、浅深色层、物体轮廓与功能辨识度。

柔和感来自相近色阶和连贯明暗组织，没有要求全图模糊、景深模糊或把画面变成平涂。细节归并控制在中等程度，保留像素 JRPG 场景的材质与层次。

## 三时段生成方法

先对选定的 D3 编辑瀑布和材质组织，再以修订后的日景作为构图与细节基准，用原选定 T3、N3 分别参考黄昏和夜晚的色光关系。每个原始输出独立保存，保留完整提示词、输入角色、尺寸与哈希。内置工具不提供可固定的模型版本与种子，三图不能视为像素完全对齐的运行时贴图。

当前为静态概念修订。水幕、泡沫、焦散、倒影与角色水线仍是美术示意，尚未迁移到 Godot。原实验项目和验证证据没有替换。本轮不自动提交或推送。
